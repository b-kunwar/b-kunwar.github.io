## Updating the Home section

Edit `About_Me.txt` to change the Home biography. Separate paragraphs with a blank line. Start each bullet on its own line with `•` or `- `. Text is displayed as plain text; HTML is not needed. Commit and push `About_Me.txt` to publish future biography changes.

The website loads this file with `about.js`. Preview through a local HTTP server or GitHub Pages; opening `index.html` directly as a file may block loading.
