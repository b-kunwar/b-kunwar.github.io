## Updating the Home section

Edit `aboutme.md` to change the Home biography. Separate paragraphs with a blank line. Start each bullet on its own line with `•` or `- `. Markdown supports `[label](https://example.com)` links, `**bold**`, `*italics*`, and `## Headings`; HTML is not needed. External links open in a new tab. Commit and push `aboutme.md` to publish future biography changes.

The website loads this file with `about.js`. Preview through a local HTTP server or GitHub Pages; opening `index.html` directly as a file may block loading.
