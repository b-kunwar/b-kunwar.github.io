Journey is a quadcopter that will form a test bed for a series of future custom controllers. In the current version, a state feedback controller is implemented in the inner loop to stabilize the quadcopter as it is piloted remotely. The quadcopter has Pixhawk 2.4.8 as an onboard flight computer. The controller was first designed in MATLAB Simulink and uploaded to flight computer using QGroundControl and PX4.
